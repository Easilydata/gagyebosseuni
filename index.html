가계부쓰니

수입과 지출을 쉽고 간편하게 기록하는 개인 가계부 앱

서비스 소개

가계부쓰니는 사용자가 수입과 지출을 간편하게 기록하고, 소비 흐름과 현금 흐름을 확인할 수 있도록 돕는 개인 가계부 앱입니다.

주요 기능

수입·지출 관리거래 내역을 날짜와 카테고리 기준으로 기록하고 관리합니다.
고정 수입·지출매월 반복되는 수입과 지출을 자동으로 반영합니다.
분석 리포트현금 흐름, 저축률, 소비 TOP, 최근 지출 추이를 확인합니다.
데이터 백업·복원앱 데이터를 백업 파일로 저장하고 필요할 때 복원할 수 있습니다.

데이터 처리 방식

가계부쓰니는 별도의 회원가입이나 외부 서버를 사용하지 않습니다. 사용자가 입력한 데이터는 기본적으로 사용자의 기기 내부에 저장됩니다.
