개인정보처리방침

가계부쓰니는 사용자의 개인정보 보호를 중요하게 생각합니다.

서비스 소개 개인정보처리방침 문의

1. 수집하는 개인정보

가계부쓰니는 회원가입 기능을 제공하지 않으며 이름, 이메일 주소, 전화번호, 위치 정보, 금융 계좌 정보 등을 수집하지 않습니다.

사용자가 앱에 직접 입력한 수입, 지출, 카테고리, 설정 정보는 사용자의 기기 내부 저장소에만 저장됩니다.

2. 개인정보의 이용 목적

앱에 저장되는 정보는 사용자가 수입과 지출을 기록하고, 가계부 내역 및 리포트를 확인하기 위한 목적으로만 사용됩니다.

3. 개인정보의 제3자 제공

가계부쓰니는 사용자의 데이터를 제3자에게 제공하거나 판매하지 않습니다.

4. 개인정보의 보관 및 삭제

앱 데이터는 사용자의 기기에 저장됩니다. 앱 삭제 시 기기에 저장된 데이터는 함께 삭제될 수 있습니다.

사용자는 앱 내 데이터 백업 기능을 통해 데이터를 별도로 보관할 수 있습니다.

5. 외부 서버 사용 여부

가계부쓰니는 현재 별도의 외부 서버를 사용하지 않습니다. 사용자가 입력한 데이터는 개발자 서버로 전송되지 않습니다.
